# Bob Loss

Turn a photo into a loose oil painting while a softly spoken painting teacher talks you through the brushwork. The voice was created with [Gradium Voice Design](https://docs.gradium.ai/guides/voices/voice-design).

Choose a photo, press **Begin painting**, and give it a couple of minutes. Studio view keeps the painting and original photo together. Save the finished PNG or share it on X. On browsers that support file sharing, **Share image** opens the system share sheet.

Photos stay in the browser. No account, upload server, or API key is needed to try the app. The browser remembers the last photo; **Forget my photo** removes it.

## Run locally

Install [Bun](https://bun.sh), then:

```sh
bun run dev
```

Open [localhost:4317](http://localhost:4317). Space pauses or resumes, H toggles studio view, and Escape exits it. The audio, painting, and captions share the same playback clock.

```sh
bun test
bun run build
```

The build copies an explicit list of public files into `dist/`. Vercel serves `public/` as a static site, with no build step or environment variables.

## How it works

The canvas samples colours and edge directions from your photo, laying down eight passes of curved brushstrokes. Smaller passes are sparse so the broad marks and bristle texture remain visible. The final image is a painting renderer's interpretation of the photo; it isn't generated by a model at runtime.

Gradium generated the original voice from the description in `session.ts`. The same prepared narration plays for every photo. The browser adds soft tape hiss and brush sounds. **Sound off** mutes all audio.

X's web intent pre-fills the prompt and site link. **Share on X** also downloads the painting so you can attach it yourself; a web intent cannot attach a local PNG automatically.

## Make your own narration

The checked-in MP3s work without credentials. To regenerate them, put `GRADIUM_API_KEY` in a local `.env`, install FFmpeg, and use:

```sh
bun run voices
bun run render:voice
```

Edit `session.ts` for the voice description and eight narration chapters. The scripts save candidates and the kept voice in ignored `data/` files, reuse completed renders, and export only generic narration into `public/`. Auditions and the final render use the `default` Gradium model.
